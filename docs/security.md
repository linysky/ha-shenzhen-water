# 凭据安全与排障

手机号、户号、地址、姓名、CodeId、openid、utoken、Cookie、二维码、验证码、完整响应、抓包、HA `.storage` 和配置备份都不应公开。仅截图遮住一部分仍可能泄露。

- 找不到集成：检查目录层级、依赖安装错误与 HA 重启是否完成。
- 传感器不可用：检查网络和认证；`unknown`/`unavailable` 不等于 0。
- 小程序正常但 HA 失败：小程序可能已获取新会话，而 HA 仍用旧会话。
- 抓包时仅代理自己有权访问的账户，限定目标域名；证书与私钥不要提交 Git、放进共享盘或公开备份，用完移除信任并恢复代理设置。
- 不要在 issue 上传私密文件；仅报告集成版本、HA 版本、错误类别和脱敏复现步骤。
- 凭据存于 HA `.storage`，请勿公开配置备份；分享日志前必须脱敏。
