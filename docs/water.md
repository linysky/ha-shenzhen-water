# 深圳水务 · 环水管家

安装 `custom_components/shenzhen_water` 后重启 HA，添加“深圳水务”。首次需要从自己已登录的环水管家获得会话 JSON；**不是只填户号就能登录**。

## 先登录环水管家并绑定账户

1. 在微信搜索 **环水管家**，核对深圳环境水务集团相关官方主体后进入，不要误入其他城市水务小程序。
2. 根据当前页面完成隐私协议及登录：若提供手机号快捷授权则确认本人号码；若提供短信登录则输入本人手机号、获取并填写验证码。首次可能还需按官方要求完成实名校验。
3. 在账户管理/绑定用户入口，按页面提示绑定本人的水务户号。户号来自自己的官方账单，不能使用文档或截图里别人的号码。
4. 确认首页能选到已绑定账户，且“历史账单”能显示月份列表，再做下面的抓包。

这里的手机号授权、短信和实名校验均由官方小程序处理，本集成不会代发短信或收集密码。不同版本按钮名称可能变化，以上是流程指引，不是固定按钮坐标。

## 获取首次配置

1. 安装 mitmproxy，例如 `uv tool install mitmproxy`。
2. 启动本机代理，**只解密水务域名**。下面示例为普通本机 HTTP 代理；需将运行微信设备的 HTTP/HTTPS 代理设置为 `127.0.0.1:8080`。不要开放到公网。

   ```bash
   mkdir -p private
   chmod 700 private
   umask 077
   mitmdump --listen-host 127.0.0.1 --listen-port 8080 \
     --allow-hosts '^szgk\.sz-water\.com\.cn(:443)?$' \
     --set 'save_stream_filter=~d szgk\.sz-water\.com\.cn' \
     -w private/water.flows
   ```

3. 按 mitmproxy 官方文档安装并信任**该代理实际使用的证书**，完全退出再打开微信。若普通代理抓不到微信流量，macOS 可用 `--mode 'local:WeChat,WeChatAppEx'` 替代普通代理模式，并允许系统网络扩展。不要同时启用两种模式或另一个抓包软件。
4. 在环水管家打开账户、账单查询、历史账单，再进入一个月的明细。此步骤需要本人操作，不提供绕过微信登录的功能。
5. 停止 mitmdump，恢复原代理设置。在安装了 `mitmproxy` 和 `cryptography` 的 Python 环境运行：

   ```bash
   uv run --with mitmproxy --with cryptography python tools/water_session.py private/water.flows private/session.json
   ```

6. 将 `private/session.json` 的内容粘贴到 HA 的“会话配置 JSON”。不要粘贴到聊天、issue 或仓库。
7. 确认出现“深圳水务 最近账单”传感器，属性 `bills` 含账单及抄表明细；完成后删除抓包与临时 JSON。

转换工具只提取四类请求的配置，不读取其他网站；如果提示缺少请求，请重新访问对应页面，不要手工猜参数。已有记录不会被工具覆盖。

## 自动刷新与续期

每 6 小时刷新。认证失败时，不带旧 utoken 调用 `CustomerInfo/generaterUtoken`，使用保存的 openid/channel 获取新令牌；重新获取户号令牌后重试整轮查询一次。查询成功才持久化新令牌。
如果仍然认证失败，HA 会提示重新认证。接口业务拒绝、网络异常不无限重试，也不自动反复抓包。

已实测无效令牌恢复，不能承诺账号解绑或官方更改接口后仍可续期。

## 数据口径

- 按月展示用水量、水费、污水费、垃圾费、账单合计、应缴、欠费、违约金及抄表记录。
- **不把月度用水量均摊成“每日用水”。** 账单月份与抄表区间未必一致。
- 最多补查最近 60 期明细；实际返回多少期取决于接口，不承诺完整终身历史。
- 明细部分失败时 `partial=true`；认证失败时传感器不可用，不冒充最新数据。

本项目不提供缴费、开票、绑定/解绑或账户修改功能。
